# VIP Cyber Security & Risk Advisory Assistant

An AI-powered risk assessment and cyber-incident documentation platform designed for high-net-worth individuals, executives, and VIP clients.

## Key Features
- **VIP Profile Risk Assessment:** AI-driven analysis of potential scam threats, romance scams, and investment frauds.
- **Executive Legal Report Generator:** Automated generation of structured incident reports and timeline summaries for law enforcement or legal teams.
- **24/7 Cyber Incident Advisory:** Instant guidance on handling online security breaches and digital asset protection.

## Tech Stack
- **Frontend:** Next.js / Tailwind CSS (Dark-themed, Privacy-first UI)
- **Backend:** Python (FastAPI)
- **AI Intelligence:** Gemini API
